# Проект интернет-магазина

Это проект интернет-магазина, созданный с помощью Gjango.

Проект включает в себя несколько приложений:

- catalog
- blog
- users

### Приложение catalog
Приложение catalog отвечает за отображение страниц home и contacts, форм создания, редактирования
и удаления продуктов.

Приложение включает: 
- логику создания, просмотр, изменнения и удаления продуктов;
- класс категории продуктов;
- отображение контактных данных;
- кастомные консольные команды для удаления продуктов и добавления тестовых продуктов.

### Приложение blog
Приложение blog отвечает за отображение страниц blog и blog_note, формы для создания, редактирования
и удаления блоговых записей.

Приложение включает: 
- логику создания, просмотр, изменнения и удаления блоговых записей.

### Приложение users
Приложение users отвечает за отображение страниц login и register (формы для авторизации и
регистрации пользователь).

Также приложение включает в себя кастомную консольную команду для создания супер пользователя.
